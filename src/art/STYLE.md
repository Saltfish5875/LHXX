# 淡彩青绿美术规范

- 山水用低对比石青、石绿和薄雾，减少岩石、枝叶、建筑纹理；主体与操作区域留白。
- 纸面 `#edf5f1`，卡片 `#fafbf6`，正文 `#243f40`，次级文字 `#526c69`，主操作 `#386e68`，朱砂 `#a45248`。CSS 入口为 `shanshui.css`，Canvas / SVG 使用 `palette.ts`。
- 容器只用一层细边框和浅阴影；避免厚卷轴、叠框、强金光、噪点纹理。标题保留毛笔字，正文保留文楷。
- 图形先表达地点和动作；棋盘保留 22 种地点点景及特殊地块图形，事件保留主体插图。得失、危险、品级不能只靠相近的青绿色区分，需保留图标、印签和短标签。
- `backgrounds/celestial-landscape.webp` 与 `celestial-portrait.webp` 是按用户认可的青绿山水参考生成的本地资源。画卷通过 `landscape.ts` 复用横图；手机演出和战斗使用竖图。CSS 底色与 Canvas 程序层山提供加载失败时的底画。
- 危险使用淡墨与朱砂，身死演出允许深墨。装饰运动轻缓，并响应 `prefers-reduced-motion`；战斗命中、敌我与技能提示保持清楚。
- 新界面优先继承现有变量与组件；检查 320px 手机、常见竖屏与桌面，确保棋盘常驻、文字可读、可点击目标不被装饰覆盖。
