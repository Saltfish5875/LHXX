# 青绿山水战斗背景

参考用户提供的青绿山水纹理，通过图像生成工具制作的无角色背景。
横屏与竖屏分别构图，WebP quality 86；不包含文字、敌人、弹道或界面。
以青绿色面、少量层叠山线与平缓薄雾表现山水，弱化枝叶和建筑细节，中央留出大面积低对比战斗空间。

- `celestial-landscape.webp`：1672 × 941，横屏取景。
- `celestial-portrait.webp`：940 × 1672，手机竖屏取景。

`src/battle/background.ts` 按屏幕方向延迟加载、缓存取景，叠加轻微视差与柔边流云。
加载中或资源失败时使用程序绘制的云海山峰；减少动态效果偏好关闭装饰性运动。
