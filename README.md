# 轮回修仙幸存者 · R12 网页原型

按 R12 三份文档（设计案、系统设计案、内容库）做的浏览器可玩原型。每年做一个决定，劫难里把这一世带进战斗，死后回到轮回井，带着天书、命灯和宿慧开始下一世。

> 这是一套新写的代码，**不是**本地 `F:\AiProject\LHXX\web` 那份工程。技术栈和画风参照它：Canvas2D 战斗视图，淡蓝水墨风。为了好跑，这里没用 Phaser，只用了 Vite + TypeScript + 原生 Canvas。

## 运行

```bash
npm install
npm run dev        # 本地开发，浏览器打开终端里提示的地址
npm run build      # 类型检查 + 打包到 dist/（相对路径，可直接放静态托管，例如 GitHub Pages）
npm run sim -- 40 all 1   # 无界面批量模拟：[世数] [safe|chance|war|all] [种子]
```

存档放在浏览器 localStorage 里（`lhxx.web.meta.v3` / `lhxx.web.life.v3`），每圈自动存一次，刷新页面后可以继续这一世。重置在「设置」里。

## 操作

- 人生层（命途棋盘）：先点盘心的「掷骰」（或空格 / 回车）摇出一颗骰，再点骰子（或按 1）走到它指的格；不满意就点「再摇一次」（或按 R）。再摇次数属于本世，开局 1 次，事件、天机格骰签、入宗门能多拿，死后清零。勾上「自动摇」只是自动揭开点数，不会替你再摇。走完一格，结果先在棋子那格冒一个小提示，详情仍在上方画卷左上角；也可以先点格子看说明，再点一次发光的格子走过去。`窥命` 消耗每圈的改命次数（点地点格）；`如意骰` 任选点数；`回溯` 需要掌天瓶，只能在一圈开头用；`自动` 按设置里的倾向替你掷骰、打理产业和天机格（遇到引子、故人、遗迹、劫气积聚的岁首或血量低于 30% 时会停下）。
- 劫难：`WASD` / 方向键移动，功法自动出手；`1` `2` `3` 用主动法宝（手机是右下的圆钮），`Q` 收剑，`P` 暂停。战斗里没有升级三选一了，打完会显示各功法出力。
- 行囊：顶栏「行囊」、角色栏「功法」旁的「行囊」，或出征、闭关、坊市弹窗里的「打开行囊」。卷轴式界面：左边是打坐的自己，身边四个功法位、两个随身位，脚下三个符丹位，下面是属性与当前加成；右边按「全部 / 法宝 / 随身 / 符丹 / 附诀」翻页查看。点任意一格看详情，在详情里换法宝、装备或取下、挂上或取下附诀、选引雷目标；新得的东西会自动填进空位。
- 手机：竖屏优先。顶部状态条点开是角色详情；劫难里按住屏幕任意处拖动即可移动，右上角暂停，右下角收剑。可以「添加到主屏幕」当 App 用。

## 已知缺口

- 修炼与法宝相对现行文档的简化：被动 / 主动法宝没有品级；器灵统一为伤害 +8%；天阶「绝技」统一为圆满后伤害 ×1.25；功法残页只来自奇遇事件和坊市（30% 概率上架）；灵器以上的法宝只记入遗泽，还没有变成遗迹秘库的专属奖励；身份的专属开局只做了数值（灵石、属性、道途、宗门功法、法器），宗门产业开局还没落地；A02「凡俗奇遇 +10%」只记成就、效果未做；A10、A25 的奖励文档没写明，暂定宗门 +2、顶级 +1。战斗的整体倍率 `BATTLE_POWER` = 1.1 是按模拟胜率对齐改版前定的。

- 命途棋盘是按 `npm run sim` 初调的：改成一颗骰加再摇后，每世约 50–60 圈、每圈停 3.4 格，遭遇战稳健约 5 场、求缘约 7 场、好战约 7 场（劫气积聚改为连续 8 圈未战才起、一战即散），自动模式每世用掉约 10–13 次再摇；每世要掷约 200 次骰，比去向卡时（约 90 次）多，「自动摇」能省掉一半的点击，真人试玩后可能要再缩短一圈的停格数。佛子「受具足戒」目前只给修炼 ×1.1，内容库里的「破戒代价翻倍」还没做。
- 一人千面里有几处是近似实现：心魔难度体现为镜像血量，妖潮减伤借用布阵效果，「改命 +2」在下一年生效，「道心」条件换成了悟性/气运；Y10 的奖励给功德与灵感，不推进心愿；海国年没有海妖专属画面。
- 「玩家就是打碎天门的人」这一反转还没定，相关内容没有做。
- 命途分岔的比例按随机选择的模拟调的（入道的世约两成走到修为尽头，其中约一半等到转机），真人会更多地避开歧路，需要试玩再调。
- 数值是按文档目标初调的，靠 `npm run sim` 看指标，还没经过真人试玩。
- 美术是程序绘制的（风格见下），还没有手绘素材和背景音乐。

## 美术与表现：「青冥画卷」

世界是一幅画：云海之上的青绿仙境，石柱仙峰、瀑布、白金仙宫、白衣御剑的青光，墨潮是这幅明亮画面里唯一的纯黑。全部用 Canvas / CSS 程序绘制，不依赖外部素材。

- 画卷舞台（`src/art/scene.ts`）：卷轴上方的横画，按年代换天色、按境界换青绿浓淡、按地点换点景（22 个地点）、按年纪换小人，劫气重时墨从画底漫上来，死后转到轮回井。
- 关键时刻演出（`src/art/moments.ts`）：入世展卷、测灵根、入道、破境、劫难开场、身死、得天书，点按可跳过。
- 音效（`src/art/sound.ts`）：WebAudio 现场合成的古琴、磬、鼓、锣，设置里可关。
- 字体：马善政毛笔楷书（标题、大字）与霞鹜文楷（正文），均为 SIL OFL，按游戏用字裁剪在 `src/art/fonts/`；文案改动后跑 `python3 scripts/subset-fonts.py <MaShanZheng.ttf> <LXGWWenKai.ttf>` 重新裁剪。

```
scripts/       批量模拟脚本
```
